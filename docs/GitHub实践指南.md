# GitHub 入门实践指南

## 🎉 恭喜你完成实践！

能进入 [HFUT-Study-Sharing](https://github.com/ByteLover-XU/HFUT-Study-Sharing)，并找到这份指南，就说明你已经掌握了使用 GitHub 查找学习项目的第一步。

### 任务一：认识仓库
1. 阅读仓库首页的 `README.md`。
2. 打开 [资料目录](原始资料目录.md)，了解课程资源分类。
3. 点击 `PPT/`、`扩展/` 等目录（上传完成后开放），浏览文件。

### 任务二：下载学习资料
1. 在仓库主页点击绿色 **Code**。
2. 选择 **Download ZIP**，下载仓库快照。
3. 解压后打开课件，选一个章节结合教材学习。

> 注意：仓库包含较大的 PPT/PDF 文件，下载完整 ZIP 需要一定空间和网络流量。

### 任务三：进阶挑战（可选）
安装 Git 后，在终端执行：

```bash
git clone https://github.com/ByteLover-XU/HFUT-Study-Sharing.git
```

克隆成功后，打开 README，或者创建自己的学习笔记仓库。

### 你学到了什么？
- GitHub 的仓库（Repository）是什么
- README 的作用
- 如何浏览目录与下载文件
- 如何通过 Git 获取和管理项目

欢迎把学到的知识整理成自己的 Markdown 学习笔记！
