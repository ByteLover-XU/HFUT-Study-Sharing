# 课程 PPT / PDF 上传说明（维护者）

本仓库的二进制资料已整理为：

```text
PPT/             15 份课程课件（.ppt）
扩展/            4 份 PDF + 1 份课堂测试（.pptx）
电路笔记.pdf     1 份
```

## 为什么不用浏览器直接上传全部文件？

GitHub 网页上传每个文件限制为 **25 MiB**。提供的部分 PPT / PDF 超过了这个大小；但本次整理的各个单文件均小于 100 MiB，因此可通过 Git / GitHub Desktop 提交，而无需拆分单个课件。

## GitHub Desktop 上传方法

1. 安装并登录 [GitHub Desktop](https://desktop.github.com/)。
2. 在 **File → Clone repository** 中选择 `ByteLover-XU/HFUT-Study-Sharing`。
3. 进入克隆得到的本地文件夹，把 `PPT/`、`扩展/` 和 `电路笔记.pdf` 复制进去（不要把整个压缩包放进去）。
4. 回到 GitHub Desktop，填写 Summary：`Add circuit course materials`。
5. 点击 **Commit to main**，再点击 **Push origin**。
6. 打开网页仓库并刷新，检查三个资源位置是否出现。

注意：此仓库为公开仓库；上传前确认课件/PDF 的公开分发许可，并检查个人信息。
