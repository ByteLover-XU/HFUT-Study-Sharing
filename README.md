## ✅ GitHub 实践成果与任务

1. **认识仓库**：在主页阅读这份 `README.md`，了解项目用途和目录结构。
2. **查找文件**：打开 [原始资料目录](docs/原始资料目录.md)，找到想学习的章节。

### 推荐的学习顺序

- **基础部分**：基尔霍夫定律 → 电路等效变换 → 网孔/结点分析 → 电路定理。
- **动态电路**：电容电感 → 一阶电路的时域分析。
- **交流分析**：相量法 → 正弦稳态分析 → 谐振与频率响应。
- **拓展部分**：三相电路、非正弦周期电流、复频域分析和二端口网络。
